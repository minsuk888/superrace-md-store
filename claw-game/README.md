# 🕹️ SUPER RACE 3D 인형뽑기 (QR 폰 컨트롤러 · 멀티플레이)

현장 이벤트용 인터랙티브 게임입니다. 큰 화면(키오스크/TV/빔프로젝터)에 3D 인형뽑기 기계가 16:9로 꽉 차게 표시되고,
관람객이 QR을 스캔해 **이름을 입력하면 자기 이름표가 달린 집게**가 생겨서 **최대 4명이 동시에** 뽑기를 즐깁니다.

## 경품 지급 흐름 (현장 관리자용)

1. 참가자가 캡슐을 뽑으면 **참가자 폰에 경품 교환권**이 뜸 — 상품명 + 당첨자 이름 + 교환코드 + 시각
2. 동시에 **큰 화면 우측 "당첨자" 목록**에도 같은 이름/상품/교환코드가 표시됨
3. 관리자는 참가자 폰의 교환권과 큰 화면의 코드를 **대조 확인** 후 경품 지급
4. 교환권은 폰에서 닫아도 "🎁 내 경품 보기" 버튼으로 다시 열 수 있음 (여러 개 당첨 시 카드 탭으로 넘겨보기)

## 구성

| 파일 | 용도 |
|---|---|
| `index.html` | 대형 화면용 — 3D 기계 + QR + 당첨자 목록 |
| `controller.html` | 폰 컨트롤러 — 이름 입력 → 조이스틱/잡기 → 경품 교환권 |
| `lib/` | three.js / mqtt.js / qrcodejs (로컬 포함 — CDN 장애 무관) |

- **연결**: 공개 MQTT 중계 서버(웹소켓) 경유 — 별도 서버/백엔드 불필요
  - WebRTC/P2P를 쓰지 않아 **셀룰러(LTE/5G) 폰 ↔ 와이파이 화면** 조합에서도 안정적으로 연결됨
  - 중계 서버 3곳(EMQX/HiveMQ/Mosquitto) 자동 페일오버, 순단 시 자동 재접속·자동 재입장
  - `?b=wss://...` 파라미터로 자체 브로커 지정 가능 (QR에 자동 반영)
- 동시 4명 초과 접속 시 자동 대기열 (자리가 나면 순서대로 입장)
- 폰 없이도 키보드(방향키+스페이스)로 테스트용 집게 생성 가능

## 실행 방법 (GitHub Pages)

1. 저장소 **Settings → Pages** 에서 Source를 `main` 브랜치로 설정
2. 큰 화면에서 접속: `https://<계정>.github.io/superrace-md-store/claw-game/`
3. 참가자는 화면의 QR 스캔 → 이름 입력 → 플레이

> ⚠️ 큰 화면과 폰 모두 인터넷 연결 필요 (현장 와이파이/LTE 모두 OK). HTTPS 호스팅이면 어디든 동작 (GitHub Pages / Vercel / Netlify).

## 게임 규칙

- 조이스틱으로 자기 집게 이동 → **잡기!** 버튼으로 하강
- 캡슐 중심에 가까울수록 잡을 확률↑ (최대 92%), 운반 중 미끄러질 수 있음
- 배출구에 넣으면 당첨 — 캡슐마다 경품이 미리 배정되어 있음 (열어봐야 아는 랜덤 뽑기)

## 커스터마이징 (`index.html` 상단 상수)

- `PRODUCTS` — **경품 목록/이모지/가중치** (가중치 높을수록 잘 나옴) ← 실제 이벤트 경품으로 교체
- `MAX_PLAYERS` — 동시 플레이 인원 (기본 4, 색상 배열도 함께 늘릴 것)
- `PRIZE_COUNT` — 캡슐 개수
- `closing` 단계의 `q = clamp(1.05 - dist*1.8, 0.15, 0.92)` — 당첨 난이도
- `HOLE` — 배출구 위치/크기, 마퀴 텍스트·브랜드 컬러 등
