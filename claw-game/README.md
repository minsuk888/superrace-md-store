# 🕹️ SUPER RACE 3D 인형뽑기 (QR 폰 컨트롤러)

현장 이벤트용 인터랙티브 게임입니다. 큰 화면(키오스크/TV/빔프로젝터)에 3D 인형뽑기 기계가 표시되고,
관람객이 화면의 QR 코드를 폰으로 스캔하면 폰이 조이스틱 컨트롤러가 되어 집게를 조종합니다.

## 구성

| 파일 | 용도 |
|---|---|
| `index.html` | 대형 화면용 — 3D 인형뽑기 + QR 코드 표시 |
| `controller.html` | 폰 컨트롤러 — QR 스캔 시 자동으로 열림 |

- **3D 렌더링**: Three.js (물리 시뮬레이션 포함 — 캡슐 굴러다님, 집게 미끄러짐 등)
- **폰 ↔ 화면 연결**: WebRTC (PeerJS 무료 공용 서버) — **별도 서버/백엔드 불필요**
- 여러 명이 QR을 스캔하면 첫 번째 사람이 플레이, 나머지는 대기열로 자동 처리
- 폰 없이도 키보드(방향키 + 스페이스)로 테스트 가능

## 실행 방법 (GitHub Pages)

1. 저장소 **Settings → Pages** 에서 Source를 `main` 브랜치로 설정
2. 배포 후 큰 화면에서 접속:
   `https://<계정>.github.io/superrace-md-store/claw-game/`
3. 화면 우측 상단 QR을 폰으로 스캔 → 컨트롤러가 열림 → 플레이!

> ⚠️ 큰 화면과 폰 **둘 다 인터넷 연결**이 필요합니다 (현장 와이파이/LTE 모두 OK).
> HTTPS 호스팅이 필요하므로 GitHub Pages, Vercel, Netlify 등 아무거나 사용 가능합니다.

## 게임 규칙

- 조이스틱으로 집게 이동 → **잡기!** 버튼으로 집게 하강
- 집게가 캡슐 중심에 가까울수록 잡을 확률이 높음 (최대 92%)
- 잡은 후 이동 중 미끄러져 떨어질 수도 있음 (실제 뽑기 기계처럼 😄)
- 캡슐이 배출구에 들어가면 🎉 당첨 — 화면 폭죽 + 폰 진동

## 커스터마이징 포인트 (`index.html` 상단 상수)

- `HOLE` — 배출구 위치/크기
- `spawnPrizes(14)` — 캡슐 개수
- `closing` 단계의 `q = clamp(1.05 - dist*1.8, 0.15, 0.92)` — 당첨 난이도
- 마퀴 텍스트("SUPER RACE 뽑기"), 브랜드 컬러 등
